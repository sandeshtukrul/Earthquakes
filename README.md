# Earthquakes

## Introduction
Welcome to the Earthquakes project! This project aims to provide tools for analyzing and structuring earthquake data fetched from remote APIs. By leveraging these tools, users can gain insights into earthquake occurrences. This project is ideal for researchers, data scientists, and enthusiasts interested in understanding earthquake patterns and impacts.


## Features

- Fetch earthquake data from external database.
- Provide structured data outputs.
- Basic visualization of earthquake occurrences.

## Installation

1. Clone this repository
2. Open the project in Android Studio.
3. Build and run the project on your Android device or emulator.

## Data

The data used in this project is sourced from USGS Earthquake API.
